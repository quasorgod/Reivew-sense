# ReviewSense — Deep Learning Sentiment Analysis

A comprehensive comparison of **Machine Learning vs Deep Learning** for movie review sentiment analysis, demonstrating why **Transformer-based models (DistilBERT)** outperform classical ML approaches on nuanced text.

## Why Deep Learning?

| Aspect | ML (TF-IDF) | DL (Transformer) |
|--------|-------------|-------------------|
| Text representation | Bag of words (no order) | Contextual embeddings (self-attention) |
| Negation handling | ❌ "not good" → sees "good" | ✅ Understands "not good" = negative |
| Sarcasm detection | ❌ Misses ironic tone | ✅ Captures context clues |
| Transfer learning | ❌ Trains from scratch | ✅ Pretrained on billions of words |
| Modern NLP foundation | ❌ Legacy approach | ✅ Powers GPT, BERT, Claude, Gemini |

## Quick Start

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Run the ML vs DL comparison (generates results/)
python -I train_comparison.py

# 3. Launch the dashboard
streamlit run app.py
```

### Training options
```bash
python -I train_comparison.py                 # default: 5000 train, 1000 test
python -I train_comparison.py --train 10000   # more training data
python -I train_comparison.py --quick          # fast demo (2000 train, 500 test)
```

## Syllabus Coverage

- **AI, ML & DL Fundamentals**: Complete ML vs DL comparison with real metrics
- **Generative Models**: Transformers, self-attention, BERT/GPT/Claude/Gemini
- **Evolution of Generative AI**: Timeline from RNNs to modern LLMs
- **Industry Applications**: Case studies from Flipkart, HDFC, Jio, Netflix, Google, Amazon
- **Challenges & Limitations**: Hallucination, bias, cost, privacy, interpretability

## Tech Stack

- **Deep Learning**: HuggingFace Transformers, PyTorch, DistilBERT
- **Machine Learning**: scikit-learn (Naive Bayes, Logistic Regression, SVM, Random Forest)
- **Data**: Stanford IMDB Movie Reviews (50,000 reviews)
- **Frontend**: Streamlit with custom CSS
- **Deployment**: Streamlit Cloud compatible
